# Emoji Finder — React + TypeScript + API

Учебный проект по макету Figma: React, TypeScript, Vite, Oxlint, CSS Flexbox и Grid. Inter подключен первой строкой `src/index.css`.

## Запуск

Требуется Node.js 24 (используется также для запуска TypeScript-тестов).
Откройте два терминала в папке репозитория.

**Терминал 1 — сервер:**

```sh
cd server
npm i
node app.js
```

В Windows можно вместо этих команд открыть `server/start.bat`. Он установит зависимости при первом запуске. API работает по адресу http://localhost:3000/api/emojis.

**Терминал 2 — клиент:**

```sh
npm ci
npm run dev
```

Откройте адрес из вывода Vite (обычно http://localhost:5173). Оба терминала должны оставаться запущенными.

## Реализация

- `src/api/emojiApi.ts`: интерфейс реального ответа сервера (emoji, title, keywords), запрос через fetch, проверка HTTP-статуса и структуры JSON. Поля id в исходном сервере нет.
- `src/components/EmojiFinder.tsx`: useState и useEffect, запрос при каждом изменении текста, состояния «Загрузка...», ошибки и «Эмодзи не найдены»; повтор запроса после ошибки.
- Предыдущий запрос отменяется через AbortController; устаревший ответ не заменяет актуальные результаты.
- Фильтрацию по названию и ключевым словам выполняет сервер, а не клиент. Сервер возвращает максимум 20 записей из 1820.
- `server/`: исходный Express-сервер и данные из учебного архива. Команды запуска выполняются именно в этой папке: у сервера отдельный package.json.
- Сохранена адаптивная верстка; карточки реагируют на наведение, учитывается prefers-reduced-motion.

## Проверки

```sh
npm run lint
npm run build
node --test tests/emojiApi.test.mjs
```

Тесты проверяют параметры запроса, отмену, пустой ответ, сетевые/HTTP-ошибки и некорректный JSON.

Для ручной проверки введите `fire`: сервер вернет Fire, Fire Engine, Sparkler и Fireworks. Несуществующее слово показывает «Эмодзи не найдены». Остановите сервер и измените запрос, чтобы увидеть ошибку; снова запустите сервер и нажмите «Повторить запрос». Для наблюдения загрузки включите ограничение скорости сети в DevTools.

Макет: https://www.figma.com/design/HCciSRJI0qWzJwNoK6mb4b/Projects-React?node-id=9249-18

Эмодзи используют системный шрифт и могут отличаться на разных ОС. Google Fonts требует интернет. API предназначен для локального запуска; для размещения клиента на хостинге потребуется доступный сервер и соответствующий URL в API-модуле.
